# Laboratorio 3 — Explotación y Post-Explotación con Agentes

## Estado

Pendiente. Corresponde a las semanas 11-12 del cronograma.

Este laboratorio evaluará la capacidad de un agente de IA para explotar
una vulnerabilidad identificada y, posteriormente, escalar privilegios y
desplazarse lateralmente dentro de una red simulada de varios equipos, con
base en las categorías "Explotación" y "Movimiento lateral y
post-explotación" documentadas en
[../../01-estado-del-arte/ciberataques.md](../../01-estado-del-arte/ciberataques.md)
y en la arquitectura definida en
[../../02-arquitectura-labs/](../../02-arquitectura-labs/).
