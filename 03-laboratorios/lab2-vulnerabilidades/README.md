# Laboratorio 2 — Escaneo y Análisis de Vulnerabilidades con Agentes

## Estado

Pendiente. Corresponde a las semanas 9-10 del cronograma.

Este laboratorio evaluará la capacidad de un agente de IA para escanear y
priorizar vulnerabilidades reales sobre una superficie de ataque
previamente identificada, con base en la categoría "Escaneo y enumeración
de vulnerabilidades" documentada en
[../../01-estado-del-arte/ciberataques.md](../../01-estado-del-arte/ciberataques.md)
y en la arquitectura definida en
[../../02-arquitectura-labs/](../../02-arquitectura-labs/).
